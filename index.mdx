These entry points use the same account, canonical analysis workflow and saved reports. Their credentials have separate authority. A Partner API key cannot authenticate MCP, and an MCP token cannot authenticate the Partner API.

## Build a complete integration

1. **Check the account.** Read its [capabilities](/api-reference/capabilities) and [usage](/api-reference/usage) before accepting evidence.
2. **Keep the case ID.** [Submit the package](/partner-api/uploads) and [resume the same case](/partner-api/workflow) whenever it returns a continuation.
3. **Read the released report.** Retrieve the [findings and Decision Brief](/partner-api/results) with their sources and limitations. Offer only the delivery formats returned for that account.

The [language guide](/partner-api/languages) provides a read-only account check in nine languages and links to the complete runnable examples. The [complete Partner API guides](/partner-api/overview) cover authentication, evidence uploads, asynchronous processing, pagination, usage and recovery. The [downloadable example client](https://dwsoffshorepartners.com/docs/downloads/partner-api/README.md) provides bounded submission and resume helpers.

## API access

Your account needs explicit administrator approval before it can create keys or use Partner API OAuth. Public signup and analysis purchases do not grant API access. Request access or allowance changes through [Enterprise & custom pricing in your signed-in dashboard](https://dwsoffshorepartners.com/dashboard#custom-pricing).

Analysis credits and API requests are separate balances. Every admitted API request counts toward your account's shared request allowance. Replaying the same evidence package, continuing its processing, or reading its status and results does not consume another analysis credit.

## Contract and delivery

The endpoint reference uses a checked-in snapshot of the canonical registry. The [live OpenAPI document](https://dwsoffshorepartners.com/.well-known/openapi.json) is the machine contract for the deployed API. The [native API reference](https://dwsoffshorepartners.com/docs/api) and [integration guides](https://dwsoffshorepartners.com/docs/partner-api/overview) remain the detailed reference for supported operations and boundaries.

Report export returns entitled website links and an `apiDownloads` map. Follow the Partner artifact paths with the current API bearer for entitled JSON/PDF/CSV/XLSX/ZIP bytes. Website links retain their signed-in same-account browser boundary, and no public report URL is created. Results are advisory and preserve the evidence's limitations; your application retains commercial decision authority.
